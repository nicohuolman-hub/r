# Ohjelman nimi
    # Pallo-peli
# mitä ohjelma tekee ja kenelle se on tarkoitettu.   
   Käynnistä peli ja aloita painamalla ENTER
   Ohjaa pelaajaa nuolinäppäimillä
   Kerää keltaisia kolikoita saadaksesi pisteitä
   Vältä punaista vihollista, joka jahtaa pelaajaa
   Kun olet kerännyt 25 kolikkoa, maali avautuu
   Mene maaliin voittaaksesi pelin
   Jos vihollinen osuu pelaajaan, peli alkaa alusta
   ESC-näppäimellä voi sulkea pelin
   
# Käynnistäminen
    Varmista, että Python on asennettuna tietokoneelle
    Asenna pygame-kirjasto (jos sitä ei ole): pip install pygame
    Lataa pelin tiedostot  kansioon esim. ohjelma.py
    Avaa komentokehote tai terminaali siinä kansiossa
    Käynnistä peli komennolla: python ohjelma.py
